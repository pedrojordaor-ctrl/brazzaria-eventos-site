# Contexto do site

Lido do repositório e do site publicado em 18/11/2026.

## Stack

- Uma página só (`index.html`), HTML, CSS e JavaScript puros, sem build.
- Hospedagem no Netlify. Cabeçalhos em `_headers`, redirecionamentos em `_redirects`.
- Endereço oficial: `https://www.brazzariaeventos.com.br/` (sem `www` redireciona com 301).
- Arquivo de verificação do Google na raiz (`googlef028eaae85995510.html`): a propriedade do Search Console já foi verificada por arquivo.

## Onde fica cada coisa

- Título, descrição, Open Graph e dados estruturados: no `<head>` do `index.html`.
- Perguntas frequentes: seção `#duvidas`. O bloco `FAQPage` do `<head>` repete o mesmo texto: mudou a resposta na página, muda no bloco.
- Simulador de orçamento: seção `#orcamento`, lógica em `js/main.js`. Ao enviar, abre o WhatsApp com o resumo. Nada é gravado.
- Sitemap: escrito à mão, uma URL.
